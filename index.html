About Me

Learning by building, testing and documenting.

I'm passionate about infosecurity and penetration testing. I enjoy exploring how systems work, understanding their inner workings, discovering vulnerabilities, and learning how to approach security from an attacker's perspective.

04 / ROADMAP

Learning Path

A practical roadmap for developing programming and cybersecurity fundamentals.

PHASE_01

Python Fundamentals

Strengthen knowledge of data structures, functions, modules, exceptions, file handling, and algorithmic thinking. Build command-line applications and learn to debug them systematically.

PHASE_02

Linux and Systems

Develop confidence with the Linux command line, permissions, processes, filesystem navigation, shell utilities, and system administration.

PHASE_03

Networking and Web Technologies

Study HTTP, DNS, TCP/IP, request and response structures, cookies, authentication, and the architecture of web applications.

PHASE_04

Security Analysis

Learn to examine application behavior, analyze logs, understand common vulnerability classes, and investigate security issues in authorized labs and deliberately vulnerable applications.

PHASE_05

Practical Security Projects

Turn theory into small tools, document reproducible findings, write clear technical reports, and improve projects through testing and code review.
